# 商洛文旅数字平台 · 完善版

> 22℃商洛 · 中国康养之都
> 本项目已完成前后端分离、AI 性能优化、持久化存储以及一键公网发布功能。

---

## 一、项目核心改进

1.  **AI 性能极速优化**：
    - **秒回策略**：核心旅游问题优先匹配本地语料库，实现零延迟响应。
    - **并发请求**：非核心问题同时请求豆包大模型与联网通道，哪个快用哪个。
    - **智能降级**：网络异常或 AI 繁忙时自动展示本地精品线路。
2.  **一键公网发布**：
    - 内置 `localtunnel` 隧道，执行 `npm run publish` 即可生成全球可访问的链接。
3.  **持久化聊天记录**：
    - 引入 `localStorage` 机制，对话记录在刷新页面后依然保留。
4.  **动态数据一致性**：
    - 首页统计数字（景区数、美食数等）从后端数据库实时计算，确保文案永远准确。
5.  **工程化升级**：
    - 引入 **SQLite 数据库** 存储业务数据。
    - 顶部导航增加**路由进度条**，消除跳转迟滞感。
    - 适配局域网多设备访问。

## 二、运行与发布指南

### 1. 准备工作（仅需一次）
在项目根目录执行：
```bash
npm run install-all
npm run init-db
```

### 2. 模式 A：本地/局域网开发（推荐）
启动服务：
```bash
npm start
```
- **本机访问**：`http://localhost:3001`
- **局域网访问**：控制台会显示你的 IP（如 `http://192.168.x.x:3001`），手机或其他电脑连接同一 Wi-Fi 即可访问。

### 3. 模式 B：全球公网发布（分享给朋友）
如果你想让外地的朋友也能打开，只需执行：
```bash
npm run publish
```
- 控制台会输出一个 `Global URL: https://xxxx.loca.lt`。
- **首次访问**：需要输入你的公网 IP 作为密码（控制台会直接打印出该 IP）。

## 三、发布 Checklist（上线前必看）

如果你打算将本项目部署到云服务器（如阿里云、腾讯云）进行**正式发布**，请检查以下事项：

- [ ] **环境变量**：确保生产环境的 `.env` 文件已配置正确的 `ARK_API_KEY`。
- [ ] **端口安全**：在云服务器控制台安全组中开启 `3001` 端口。
- [ ] **域名与 SSL**：正式发布建议购买域名并配置 HTTPS。
- [ ] **进程守护**：建议使用 `pm2` 启动服务，确保崩溃后自动重启：
  ```bash
  npm install -g pm2
  pm2 start backend/server.js --name "shangluo-tourism"
  ```

## 四、技术架构

- **前端**：Vanilla JS + ECharts + CSS3 动画（响应式适配移动端）。
- **后端**：Node.js + Express。
- **数据库**：SQLite (better-sqlite3)。
- **AI 能力**：火山方舟（豆包 1.5 旗舰版） + Pollinations 联网增强。
- **内网穿透**：Localtunnel。

## 五、开发者说明

- **修改内容**：若需修改景区、美食等数据，请编辑 `backend/data/content.json` 后重新运行 `npm run init-db`。
- **修改样式**：全局样式位于 `frontend/css/style.css`。
- **API 密钥**：在 `backend/.env` 中管理，切勿上传到公开 Git 仓库。
